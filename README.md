V tomto repozitáři se nachází kódy a datasety pro diplomovou práci zabývající se odhadem orientace RFID tagu pomocí metod strojového učení. Repozitář obsahuje čtyři složky. Dvě složky se skripty: Python pro automatizaci Ansys HFSS a MATLAB pro zpracovávání výsledků z HFSS a aplikaci algoritmů ML. Třetí složka PTS\_soubory\_definujici\_rozestupy\_sond obsahuje .pts soubory, které jsou potřeba definici míst, odkud se budou ze simulačního prostoru v HFSS odečítat Re a Im složky pole. Poslední složka Datasety obsahuje všechny získané hodnoty z HFSS, které jsou určeny pro zpracování v MATLAB.
